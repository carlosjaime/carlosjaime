## Proyectos destacados

### TaquerOS

Plataforma digital para taquerías que centraliza caja, cocina, inventario, ventas, pedidos y sucursales en una sola experiencia.

El sistema está diseñado para optimizar la operación diaria de taquerías, mejorar la atención al cliente, reducir errores en pedidos y ofrecer una mejor visibilidad del negocio mediante una interfaz moderna, intuitiva y enfocada en la productividad.

Tecnologías y enfoque:

- Next.js.
- JavaScript / TypeScript.
- UI/UX mobile-first.
- LocalStorage para modo demo.
- Dashboard administrativo.
- Gestión de mesas.
- Gestión de pedidos.
- Gestión de productos.
- Control de ventas.
- Preparación para backend PHP + MySQL.

### TallerCheck

Aplicación orientada a talleres mecánicos, clientes y refaccionarias.

El objetivo de TallerCheck es conectar en una sola plataforma a clientes, mecánicos y refaccionarias, facilitando la gestión de citas, refacciones, seguimiento operativo, comunicación y notificaciones.

Funcionalidades principales:

- Gestión de citas.
- Tienda de refacciones.
- Roles de cliente, mecánico y refaccionaria.
- Notificaciones push.
- Tracking.
- Experiencia mobile-first.
- Backend PHP / MySQL.
- Flutter para app móvil.
- Interfaces optimizadas para operación diaria.
